## 一句话结论

**可逆 + 球数守恒可以 by construction 焊进一个学习模型，且经验证在所有长度上精确成立。但给出这些保证的那个"局部门控交换"结构太弱，学不会 BBS 规则（准确率停在平庸基线）。** 两个学习模型正好互补:搬运工表达力强但不守恒;可逆 CA 精确守恒但表达不了规则。真正的路线 C 必须把两者合一。

## 四个模型

| # | 线 | 结构 | 规则 | 可逆 / 守恒 | 角色 |
|---|---|---|---|---|---|
| 1 | 硬编码可积 | BBS 搬运工规则 | 写死（作弊） | 结构自带、精确 | 天花板 |
| 2 | 学出来的搬运工 | 权重共享的左→右扫描（非局部 reach） | **学** | 近似（会漂） | 表达力强、无保证 |
| 3 | **可逆+守恒 CA（路线 C）** | 相邻对的门控交换;门只读被冻结的邻居 + 交换不变的对内总和 | **学** | **结构自带、精确** | 有保证、但局部 |
| 4 | Transformer | 通用注意力 | 学 | 无 | 下界 |

**#3 的保证，训练前就验证了**(随机初始化下自检):球数精确守恒、且 `invert(forward(x)) == x` 精确成立,L = 32/48/64/96/128 全过。交换保守对内总数、且是自己的逆;门只读本层冻结的格子 + 交换不变的对内总和 → 整个堆栈**无论学成什么都精确可逆**。

## 解读

**① 保证能焊进去(正面、已验证)。** 路线 C 的守恒在所有长度上是平的 100%、可逆精确——靠结构、不靠学,所以永不漂。这正是上个原型的搬运工给不了的东西。

**② 但这个结构学不会规则(负面、诚实)。** 路线 C 的准确率停在 ~82%——基本就是全 0 / 恒等基线的水平;训练 loss 卡在 ~0.15,而搬运工能到 ~0.02。局部门控交换只能在相邻格之间挪球、且靠局部决策;而 BBS 的搬运依赖左→右累积的进位计数,这个局部门 + 浅层堆栈抓不住。守恒在这里没给准确率买来任何东西。

**③ 这个张力就是发现本身。** 两个学习模型分处对角:
- **搬运工(#2):** 非局部 reach → 学会了规则(所有长度 99.5%),但只近似守恒(96→82% 往下漂)。
- **可逆 CA(#3):** 精确守恒 + 可逆 by construction,但局部结构表达不了规则(~82%)。

谁都没同时占全。**保证和表达力目前住在两个不同的架构里。**

## 诚实边界

1. **单次运行、单种子、玩具规模。** 数字随种子波动(这次搬运工看起来比上个原型实验里更强,正是同一个原因)。
2. **#3 的负面结论是针对*这个*结构的,不是不可能性证明。** 局部门控交换只是可逆/守恒族里的一种;它学不好 BBS,不代表没有可逆+守恒模型能学好。而且离散路由本身难训(这里用了 soft 训练 / hard 评测、温度退火)。
3. **可靠的是:** 结构保证本身(验证精确),以及"互补取舍"这张图。

## 下一步（真正的路线 C）

把两个角落合起来:一个既有搬运工那种**左→右 reach**、又有 #3 那种**结构可逆 + 守恒**的模型。具体做法——让**搬运工本身变得可逆且质量守恒**(一次可逆的循环扫描,搬运球而不是自由地吐出 0/1),这样单个架构同时拿到 #2 的准确率和 #3 那条平的 100% 守恒线。做到那一步,这张四路图就从"一个张力"变成"一条同时贴着两块天花板的线"。
