- **决定 / 下一步：** **不在此硬调孤子**（遵守"别硬调硬凑"）。Step 1 以可积性自检为准、判 PASS。孤子留到任务阶段解决，两条候选路：(a) 精确 tau-function 2-孤子；(b) 干脆不依赖解析孤子——用近似孤子对撞，**相移直接从精确积分器（等谱 1e-6）读**作 ground truth。倾向 (b)，更省事且同样严谨。

- **日期 / 尝试编号：** 2026-07-07 · #2（Step 2，单种子探针 v1：naive 可学习作用-角）
- **想让结构带来什么好处：** 靠 `θ(t)=θ₀+ω(I)·t` 的架构偏置，从短时(t≤5)训练外推到长时(t≤20)，跑赢自由式、并跑赢"钉死全部 N 个守恒量"的最强 bolt-on。
- **卡在哪：** **结构模型没干净外推、也没赢 bolt-on。** 状态 MSE（predict-mean≈0.245）：structural 0.03→0.50→0.63→**0.63**；free-form 0.02→…→**2.06**；bolt-on 0.28→…→**0.59**。长时间 **structural ≈ bolt-on**，且**两者都比 trivial(0.245) 还差**。期望的干净对比（bolt-on 守恒对但状态漂、结构两条都平）**没出现**。
- **归因（勾）：** ☑ 可学性/优化（R2：编码/解码没学到真的作用-角变换）+ ☑ **一个更根本的点**：`θ=θ₀+ωt` 外推需要**从短窗精确估计频率 ω**，t≤5 估的 ω 到 t=20 相位误差放大 4×→全错。**短窗频率估计是硬极限**，naive 端到端学 ω 不够准。
- **排除了什么：** 排除"结构模型没训起来"（训练窗内 0.032，拟合没问题，是*外推*失败）；排除"free-form 意外能外推"（它守恒量爆炸到 5e6、彻底离开物理流形）。
- **bolt-on 对照当前状态（最强档，钉死 N 个守恒量）：** 长时间与结构模型**打平**（0.59 vs 0.63）→ 目前**未能证否**"守恒足矣"，也**未能证成**"结构独有好处"。leaning 预注册的 **F2**。
- **决定 / 下一步：** 遵守"别硬调硬凑"——**不**调超参硬凑赢面。提出**一个有原则的迭代**（非硬调）：把**真·守恒谱（Lax 的 tr(Lᵏ)/本征值，by construction 精确）直接喂给模型作固定 actions**，让它**只学角动力学 + 解码**，隔离"角线性化 + 解码是否可学"这个真问题（IST 的难点——逆映射——仍由模型学、不硬编）。若此迭代仍平/仍漂 → firmly F2，转写负结果（"可积结构可学习化的核心障碍 = 短窗频率估计 + 逆谱解码"）。**待与 dong 确认走 (a) 有原则迭代 还是 直接判 F2。** → dong 批 (a)，已做。

- **日期 / 尝试编号：** 2026-07-07 · #3（Step 2，探针 v2：有原则迭代 = 真 actions）
- **想让结构带来什么好处：** 把**真·守恒量 tr(Lᵏ) 喂作固定 actions**（和 bolt-on 拿到同一批守恒量），治病根——频率 ω 变成真 actions 的全局函数、学一次，不再靠短窗每条估。模型只学 φ₀ + ω(I) + 解码。
- **卡在哪：** **没救回来。** 状态 MSE：v2 真 actions 0.22→0.47→0.50→**0.53**；v1 0.04→…→**0.50**；bolt-on 0.28→0.38→0.38→**0.50**；free-form →**3.08**。在有信息的 OOD 区(t5–15)**bolt-on(0.38) 反而优于两个结构模型(0.44–0.52)**；长时间所有模型都比 trivial(0.245)差。
- **归因（勾）：** ☑ 可学性/优化（**R2 是主坎**）：即便给了精确 actions，模型仍学不出"准确频率 ω(I) + 逆谱解码 D(I,角)→state"这套联合映射。N=8 准周期有 8 个不可约频率，解码要把 8D 环面 + 8 actions 非线性地拼回 16D 状态——这正是逆谱重构的难处，端到端 MLP 没拿下。
- **排除了什么：** 排除"是 actions 没学准导致"（v2 直接给真 actions 仍不行）；排除"频率靠短窗估这一条是唯一病根"（把 ω 变成全局函数仍不行）→ 病根在**解码/联合可学性**，不只频率估计。
- **bolt-on 对照当前状态（最强档，钉死 N 个守恒量）：** **未被证否，反而在 OOD 区略胜结构模型。** 即：本设定下"守恒（bolt-on）≥ 我们能学出来的可积结构"。
- **决定 / 下一步：** **判定 F2（本方法）。** 遵守承诺，不再调。**负结果（scoped、honest）**：*可学习的作用-角归纳偏置方法（编码/频率/解码皆学，actions 给真或学皆试过），在本 rough-demo 设定下未能让 Toda 的可积结构被可学习地 exploit 出时间外推优势，且不敌"钉死全部守恒量"的 bolt-on；核心障碍 = R2（准确频率 + 逆谱解码的联合可学性）。* 这**不**声称"任何方法都不行"——只 scope 到作用-角-MLP 这一路。是否(i)就此写成负结果交付 / (ii)另开一份**新预注册**换一种结构（如直接尊重 Lax 流 dL/dt=[B,L] 的"Neural-Lax"，而非作用-角）——**待 dong 定**（换结构属新尝试、非硬调）。
