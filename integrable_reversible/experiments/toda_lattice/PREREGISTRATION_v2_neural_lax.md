## 换什么、为什么

v1 走"到谱/角坐标再解码回状态"——**逆谱解码**是那个坎。Neural-Lax **不去谱坐标**：

- 状态 ↔ Lax 矩阵 `L`（Flaschka：`a_n=½e^{d_n/2}, b_n=-½p_n`，**局部、可逆、平凡**——不是 IST）。
- 动力学是**等谱 Lax 流** `dL/dt = [B, L]`：对**任意反对称 B**，`d/dt·tr(Lᵏ)=0`（循环迹），**全部 N 个守恒量结构性精确、免费**。
- **学的是生成子 B**（Toda 的规则），不硬编答案；解码回状态是平凡 Flaschka 逆 → **绕开 R2**。

## 一个必须写下的诚实张力

Toda 状态 = **三对角**（Jacobi）`L`。一般反对称 `B_θ(L)` 的流会破坏三对角、离开物理流形。
**保持三对角的等谱流几乎被钉在 Toda 层级** `B_k = skew(Lᵏ)` 上（每个 `B_k` 同时保等谱 + 保三对角）。
所以我们把生成子取为层级组合 `B_θ(L) = skew(Σ_{k=1..K} c_k Lᵏ)`，**学的是系数 `c_k`（可含 `c_k(I)`）**。

- 好处：等谱 + 三对角**都结构性成立**，解码平凡，R2 绕开。
- **代价（如实标注）：** 学习量小（真 Toda = `c_1=1` 其余 0）。所以哪怕成功，也要诚实定位为
  "**结构做了绝大部分、模型只学了生成子系数**"——不是"从零学出复杂规则"。但这仍是一次公平的
  **结构 vs bolt-on** 对照：结构给的是 Lax 形式（bias），不是答案。

## 结构模型 vs 基线（都学"向量场"，公平）

- **Neural-Lax（结构）：** `dL/dt = [skew(Σ c_k Lᵏ), L]`，学 `c_k`；训练用向量场匹配
  （拟合相邻状态的有限差分导数），评测时积分到长时。等谱结构性精确。
- **free-form：** `dL/dt = f_θ(L)`（无约束 MLP 向量场），学、积分。无结构。
- **bolt-on（最强档）：** free-form + 惩罚 `d/dt·tr(Lᵏ)=0`（k=1..N）——把"全部守恒量守恒"
  外挂到自由向量场上。这是"钉死全部守恒量"的向量场版。

## 判据（沿用 v1，卡在"外挂不出来"）

> Neural-Lax 从短时（`t≤T_train`）学生成子，积分外推到长时（`t≤T_max`），状态误差**随 t 基本持平**、
> 守恒量**结构性精确**；而 bolt-on（自由向量场 + 钉死全部守恒量）**守恒对但状态随 t 漂**。
> 量化：最大测试时长上 Neural-Lax 状态误差 < X 且 < bolt-on / k（k≥3），≥5 种子（探针先单种子）。

**证伪（任一成立即如实判负）：** (F1) bolt-on 追平 → 守恒足矣；(F2') Neural-Lax 自己也漂
（如积分/离散化把等谱流带偏、或 `c_k` 学不准）→ 记障碍、写"Lax 可学习化仍受限于 X"。

## 避坑（沿用 v1 §4）

不硬编答案（学 `c_k`、不设 `c_1=1`）；防泄露（若 `c_k` 太少导致平凡，如实标注"学习量小"这一诚实边界，
不夸大成"学出了复杂规则"）；bolt-on 给足公平预算。离散积分可能让等谱**近似**而非精确——测量并如实报。
