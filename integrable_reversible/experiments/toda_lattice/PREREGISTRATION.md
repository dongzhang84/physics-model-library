## 0. 定位：这一发要躲过"加约束"的牙齿

BBS 和 Margolus 都已用 bolt-on 对照实测证明：**守恒可外挂**（把守恒投影加到自由式模型上，守恒顶到 100），**但外挂救不回精确性**。它们补的是广度，仍在浅水区。

Toda 是**第一个真·可积系统**（真 Lax 对、真对合、真无穷守恒量）。这一发的唯一使命：**做出一个可学习的模型，它靠可积的核心结构拿到一个"加任意有限条守恒约束都复制不出来"的好处。** 判据必须卡在这里，否则又退回浅水区。

**关键洞察（决定整份判据）：** 可积 = **作用-角变量**（Liouville）。作用 `I`（= Lax 谱的函数）守恒；角 `θ` 随时间**线性**运动 `θ(t)=θ(0)+ω(I)·t`。

- 外挂守恒 = 把**作用 `I` 钉死**（能量、动量、乃至全部 N 个 Lax 本征值）。
- 但长时间状态还需要**角 `θ(t)` 演化对**——而这**外挂不出来**：钉死所有守恒量只固定了轨道所在的环面，没告诉你在环面上转到哪了。
- 结构模型（把"守恒谱 + 角线性演化"做进架构）天生拿到 `θ(t)` 的线性律 → 任意长时间外推精确。

**所以真正的照妖镜是：把全部 N 个守恒量都外挂上去，自由式模型*依然*算不准长时间状态**——这就证明可积性的好处在**角动力学（线性化映射）**里，不在守恒值里。这是"加有限约束复制不出来"的最锋利形式。

## 1. 系统：Toda 格子（为什么是它）

N 个粒子、指数近邻相互作用，`H = Σ pₙ²/2 + Σ exp(qₙ − qₙ₊₁)`。

- **真·可积**：Flaschka 变量把它写成 **Lax 对** `dL/dt = [B, L]`，`L` 是对称三对角（Jacobi）矩阵。`L` 的 N 个本征值**等谱不变**（= N 个对合守恒量）→ Liouville 可积。
- **IST / 作用-角**：本征值 `λₖ` 守恒（作用）；范数常数 / 角相位按**已知的固定速率线性演化**（角）。孤子 ↔ 离散本征值；双孤子碰撞后**相移由本征值决定、精确可算**。
- **便宜**：有限维 ODE（不是 PDE），辛积分器出真值轨迹，秒级仿真。
- **叙事血缘**：BBS 是 Toda / KdV 的超离散极限——"把探过路的玩具，还原成它背后真正的可积系统"。
- **绕开连续坎**：Toda 空间离散，先只闯"真·可积"，不同时闯"离散→连续"（那留给 KdV）。

**任务轴 = 时间外推**（BBS/Margolus 是长度外推的对应物）：训练**短时**、测试**长时**，看谁的长时间状态还准。

## 2. 可证伪的成功判据

**主判据（要立的）：**
> 一个把"守恒谱 + 角线性演化"做进架构的**可学习**模型，在**训练时长 T_train 之外的长时间 T ≫ T_train** 上，预测 Toda（含双孤子碰撞）的状态 / 孤子相移，误差**随 T 基本持平**；而自由式神经时间步进器——**即便把全部 N 个守恒量（能量、动量、乃至全部 Lax 本征值）都外挂钉死**——误差**随 T 增长**。
>
> 量化（粗糙 demo 标准）：在最大测试时长上，结构模型的状态/相移误差 < X，**最强 bolt-on 基线**误差 > k·X（k 至少 3），跨 ≥5 个种子稳定成立。

**这句为什么躲过牙齿：** bolt-on 基线钉死了**全部**守恒量（不是一两条），若它*仍*追不上，就证明好处在**角的线性演化**、不在守恒值——这是加任意有限守恒约束都复制不出来的。

**证伪条件（任一成立即判负，且如实写成负结果）：**
- **(F1) bolt-on 追上了**：钉死守恒量后自由式也能长时间外推 → "守恒足矣，Toda 没买到额外东西"。→ 负结果：*对合守恒量本身可外挂替代*。
- **(F2) 结构模型也漂**：把谱/角结构做进架构后，模型**学不出**可用的编码/解码或角频率、长时间照样漂 → "可积结构没能被*可学习*地利用"。→ 负结果：*可积结构可学习化的核心障碍是 X*（正是要记录的）。
- **(F3) 结构模型靠硬编 IST 作弊**（见 §4 避坑）→ 不算数，等于 BBS Demo-2 的同义反复。

**不要求（粗糙 demo，明确放低）：** 不要求通用、不要求打赢谁、不要求连续 KdV；只要求"**在很窄的设定（小 N、1–2 孤子）下，可积核心结构被*学*进模型、并带来一个 bolt-on 复制不出来的长时间外推优势**"。

## 3. 最小设计

**系统 / 数据。**
- Toda 格子，N ≈ 16–32，开边界（利于孤子）。辛积分器生成真值轨迹。
- 初值族：单孤子、双孤子碰撞（有解析形式，相移可精确算作 ground truth）、以及一般小扰动态。
- 训练对 = `(x(0), x(t))`，`t ∈ [0, T_train]`；测试 `t ∈ [T_train, T_max]`（时间外推）。

**结构模型（"可学习的作用-角 / 谱模型"）——三段，编码解码都*学*：**
- **编码 `E_φ`**（学）：`x(0) → (λ₁…λ_N, θ₁…θ_N)`，即谱（意在守恒）+ 角相位。
- **演化（已知结构，非学习）**：`λ` 保持不变，`θ(t) = θ(0) + ω(λ)·t`。`ω(λ)` 可选"已知律"或"从 λ 学一个函数"——即**可积的归纳偏置：角在特征值决定的频率上线性运动**。
- **解码 `D_ψ`**（学）：`(λ, θ(t)) → x(t)`。
- 因为演化对 `t` 线性/指数封闭，**长时间外推是结构自带的**；`E/D/ω` 从数据学 → 是真学习，不是硬编 IST。

**自由式基线。**
- **(B1) 自由时间步进器**：`f_θ: x(t) → x(t+Δ)`（Neural-ODE / Transformer / LSTM），滚动到长时间。
- **(B2) bolt-on 照妖镜（标准配置）**：同一个 (B1)，每步**投影到守恒量水平集**——分档做，从弱到强：能量+动量 → 全部 N 个 Lax 本征值钉死。**主对照就是最强那档（钉死全部 N 个守恒量）。**

**评测指标。**
- 状态误差 vs 预测时长 `T`（主曲线，类比 BBS 的 acc-vs-length）。
- 双孤子碰撞后**相移误差**（可解释的关键量：外挂守恒给不出相移）。
- 守恒量漂移（旁证；结构模型与 bolt-on 都应 ~0，用来说明"大家都守恒了，差距在别处"）。
- 多种子（≥5）均值 ± 误差棒 + bolt-on 三方对照图（沿用 BBS/Margolus 的 `*_bolt_on.png` 规格）。

## 4. 避坑（三条硬约束）

1. **不许硬编 IST（躲开 BBS Demo-2 同义反复）。** 结构模型的编码/解码/角频率必须**从数据学**；可积性只作**架构归纳偏置**（"谱守恒 + 角线性"），不作硬编的可微 IST 求解器。若最终是硬编解出来的，即触发 (F3)、不算数。
2. **防泄露审计（沿用 BBS 的做法）。** 检查有没有"平凡解直接拿满分"的漏洞——例如任务太简单、线性外推就够。若一个不带谱结构的平凡基线也拿高分，就把任务推难（更多孤子、更长 T、更强碰撞）。
3. **bolt-on 必须给足公平预算**（沿用 Margolus 教训）：自由式基线要调到在**训练时长内**和结构模型打平，再看长时间外推——否则"欠训"会污染结论。

## 5. 难度与风险（诚实）

- 这一发**edge 向 IST/Lax**，比 BBS/Margolus 难得多。粗糙 demo 成功率估 **~50–60%**（因为我们给的是*对的归纳偏置*、不是从零解逆散射）。
- **主要风险**：
  - (R1) 可微**本征分解 / 谱结构**的数值稳定性（简并、梯度）。
  - (R2) 解码 `D_ψ`（谱数据→状态，近亲于逆谱问题）难学。
  - (R3) 若守恒量水平集本身低维，bolt-on 基线可能意外地强（→ 可能触发 F1，那也是有价值的负结果）。
- 无论走向哪，§2 的判据都能给出**明确的成/败判定**，不会稀里糊涂。
