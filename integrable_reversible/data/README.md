# data — benchmark 数据生成器

对应 proposal §4「数据在哪里使用」。原则：benchmark 必须落在**我们的赢面**上——(a) 严格逐步演化、(b) 要求长度外推（训练短/测试长）、(c) 存在该守恒的量且过程可逆。

三类数据，从稳到激进：

- `reversible_systems/` — **①主战场**：一组离散可逆动力学生成的轨迹。BBS（复用自 [`../demos/box_ball_system`](../demos/box_ball_system)，规则核心抽到这里，demo 引用它）+ Margolus 邻域可逆元胞自动机 + Toda 格子离散轨迹。真值自带可逆与守恒，难度可调（孤立子个数、长度、碰撞次数），用一组而非单一系统直接支撑「物理库」叙事。
- `synthetic/` — **②增强（半合成、CS 味道）**：模运算累积序列、可逆逻辑电路状态追踪、括号/栈配平。题材像 ML 任务，骨子里满足三条赢面，让审稿人认可其 ML 意义。
- **③加分（可选，暂不建目录）**：公认 benchmark（LRA 中偏算法/状态追踪的子任务），证明在外推段不比 Transformer/SSM 差。开工到那一步再加。
