# models — 核心图上的三条线

对应 proposal §2（技术方案）和 §3（三条线放一张图）。

- `reversible_net/` — **路线 C，本文主角**。可逆网络骨架（coupling layers）：状态劈成 a、b，每层 `a'=a`、`b'=b+F(a)`，天生可逆（倒着减回去即可），把「完全可逆」**结构性焊死**，不靠训练。碰撞规则学进 F——F 用**局部、平移等变的交互算子**（局部卷积/邻域注意力），只让空间上相遇的单元作用，对应孤立子「传播 + 相遇才交互」。守恒先做软约束，再尝试结构性精确守恒。
- `integrable_exact/` — **路线 A，理想上界**。硬编可积规则（BBS 更新），100% 精确/守恒/可逆。复用 [`../demos/box_ball_system`](../demos/box_ball_system) 抽出的规则核心，别重抄。
- `transformer/` — **baseline，下界**。自由学习、无结构，超训练长度即崩、破坏守恒。
